## August 26, 2026

* Add support for asking agents in enabled Agent Merge sessions to update pull request branches that are behind the base branch or have merge conflicts. _[#332752: Setting to detect and auto-resolve merge conflicts](https://github.com/microsoft/vscode/issues/332752)_

* Delegated sessions appear beside their creator, inherit its custom group, and provide a **Created by** link to the source chat, making independently scoped work easier to trace. _[#331554: Show delegated child chats/sessions in the Agent Sessions UI](https://github.com/microsoft/vscode/issues/331554)_

* Completed `create_session`, `create_chat`, and targeted `send_message` tool calls show linked session or chat titles, making delegated work easier to identify and open. _[#332741: `create_session` link/artifact is ugly](https://github.com/microsoft/vscode/issues/332741)_

* Add VS Code support for session-aware Voice mode so compatible voice backends can report active and recent session status, navigate between sessions, and direct later voice turns to the selected session. _[#329488: Voice mode: add session awareness and session navigation](https://github.com/microsoft/vscode/issues/329488)_

## August 25, 2026

* The chat Artifacts pill uses a package icon instead of an archive icon, making it clearer that the pill represents generated outputs from the current session. _[#332069: Use a different icon for the Artifacts pill](https://github.com/microsoft/vscode/issues/332069)_
