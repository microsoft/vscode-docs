## October 2, 2026

* Paste column selections as rectangular blocks across successive destination lines when setting(editor.multiCursorPaste) is set to `spread`. _[#5940: Handle pasting code from column selection specially](https://github.com/microsoft/vscode/issues/5940)_

* Control whether selected-text occurrences follow the Find widget options or use case-sensitive or case-insensitive matching. _[#18239: Multiselect via ctrl+d case insensitivity makes it useless](https://github.com/microsoft/vscode/issues/18239)_

## October 1, 2026

* Track attached and detached shell processes started by the Copilot harness with the **Background Shells** pill. _[#336684: Need to provide a reasonable way to allow the user to keep track of launched processes](https://github.com/microsoft/vscode/issues/336684)_

* Add support for signing in to multiple GHE.com and GitHub Enterprise Server instances. _[#277435: GitHub Enterprise should allow multiple servers](https://github.com/microsoft/vscode/issues/277435)_

* Preserve GitHub Enterprise sign-ins when upgrading to multi-instance authentication. _[#339160: Keep GitHub Enterprise sign-ins when moving to multiple instances](https://github.com/microsoft/vscode/issues/339160)_

* Validate GitHub Copilot GHE sign-ins and prompt you to correct invalid entries. _[#339161: Copilot GHE sign-in accepts only GHE.com and repairs github-enterprise.uris](https://github.com/microsoft/vscode/issues/339161)_

* Add an experimental option to customize the Agents Window welcome phrases. _[#339038: Agents window: let users customize the new-session welcome phrases](https://github.com/microsoft/vscode/issues/339038)_

* Hide experimental Agents Window welcome phrases via the context menu. _[#339134: Enable context menu hide of welcome phrases](https://github.com/microsoft/vscode/issues/339134)_

* Keep experimental Agents Window new-session controls opaque over custom backgrounds. _[#339111: Agents window: keep experimental new-session composer opaque over custom backgrounds](https://github.com/microsoft/vscode/issues/339111)_

## September 30, 2026

* Keep the only child folder collapsed when expanding its parent in Explorer with compact folders disabled. _[#145510: Feature to disable auto-expanding on sub-folders.](https://github.com/microsoft/vscode/issues/145510)_

* Add an experimental **Run and Compare Agents...** action in the Agents Window to compare implementation attempts in isolated worktrees. _[#335085: Agents window: Compare multiple implementation attempts](https://github.com/microsoft/vscode/issues/335085)_

* Anchor the **Add Context** picker to its chat input button instead of centering it in the window. _[#338928: Anchor Add Context picker to its chat input button](https://github.com/microsoft/vscode/issues/338928)_

* Add an experimental option to place the Agents Window **Agent** picker under **Add Context** until you select an agent. _[#338936: Move the Agents Window agent picker into Add Context](https://github.com/microsoft/vscode/issues/338936)_

## September 29, 2026

* Add a **Chat: Clean Up Agent Worktrees** command to review and remove inactive agent worktrees. _[#338039: Add manual cleanup command for Agents Window worktrees](https://github.com/microsoft/vscode/issues/338039)_
