## August 18, 2026

* The execution subagent is now enabled by default for Enterprises and Pro subscribers (monthly and yearly). This subagent runs sequences of bash commands in response to a main agent query, and summarizes the results concisely. It uses Google's Gemini 3.5 Flash model as the subagent model, and reduces token consumption by 6-8% per user on average.

## August 16, 2026

* Preserve the expansion, focus, selection, and scroll position of the **Changes** view for each session in the Agents window, including across reloads. _[#331072](https://github.com/microsoft/vscode/issues/331072)_

* Open changes from current, completed, and earlier agent turns in the Agents window **Changes** editor. _[#331071](https://github.com/microsoft/vscode/issues/331071)_

## August 15, 2026

* Add a **Preview** action for local HTML files changed by an agent, so you can open them directly in the integrated browser on desktop. _[#330976](https://github.com/microsoft/vscode/issues/330976)_

## August 14, 2026

* Add support for attaching compatible Agents window sessions from the **Add Context** > **Sessions** picker. _[#330909](https://github.com/microsoft/vscode/issues/330909)_

* Add dedicated color IDs for theme authors to customize Modern UI surfaces, tabs, and Activity Bar states. _[#329717](https://github.com/microsoft/vscode/issues/329717)_

* Display authentication-provider avatars in the **Accounts** entry and Agents window account controls, with a fallback to the default account icon. _[#136889](https://github.com/microsoft/vscode/issues/136889)_

## August 13, 2026

* Add Agent Host server-side tools for renaming sessions and chats, so agents can replace generated placeholder titles with concise, meaningful names based on the work being performed. _[#329380](https://github.com/microsoft/vscode/issues/329380)_

## August 12, 2026

* Add support for closing all other tabs in a group by Alt+clicking a tab's close button, leaving the current tab and any sticky tabs open. _[#329251](https://github.com/microsoft/vscode/issues/329251)_

## August 11, 2026

* Hide the Voice Mode listening or barge-in placeholder in the chat input while you're typing, and restore it once the input is cleared. _[#330288](https://github.com/microsoft/vscode/issues/330288)_

* Add a link to configure `voice.md` instructions to the Voice Mode onboarding banner, alongside the existing settings link. _[#328083](https://github.com/microsoft/vscode/issues/328083)_

* Fixed an issue where Voice Mode instructions in `voice.md` were not applied. _[#328860](https://github.com/microsoft/vscode/issues/328860)_

## August 10, 2026

* Add support for associating HTML files with the integrated browser using the `setting(workbench.editor.associations)` setting, so they open directly in the browser instead of the text editor. _[#328545](https://github.com/microsoft/vscode/issues/328545)_

* Add subtitles and status indicators to the Chats picker in the Agents window, grouping regular, forked, and side chats separately from active subagents. _[#329176](https://github.com/microsoft/vscode/issues/329176)_

* Add support for selecting the unsaved editors count badge in the Open Editors view to jump to the first unsaved editor. _[#328907](https://github.com/microsoft/vscode/issues/328907)_

* Add a keybinding to reopen the most recently closed chat or session, mirroring how browsers reopen a closed tab. _[#329184](https://github.com/microsoft/vscode/issues/329184)_

## August 7, 2026

* Add support for running Codex sessions in the agent host with an OpenAI, ChatGPT, or other configured model provider without requiring GitHub Copilot sign-in. _[#329668](https://github.com/microsoft/vscode/issues/329668)_
