## Agents

### Agent host

The agent host lets you connect to the same agent session from multiple VS Code windows. It runs agent harnesses in a dedicated process based on the [Agent Host Protocol](https://microsoft.github.io/agent-host-protocol/) (AHP). The agent host's Copilot agent is powered by the [Copilot SDK](https://www.npmjs.com/package/@github/copilot-sdk), which aligns the agent's behavior and functionality with the Copilot CLI, the standalone GitHub Copilot app, and other Copilot products.

We're actively developing the agent host. The following screenshot shows the `Copilot` harness selected for an agent host in an editor window:

![Screenshot showing the harness dropdown in the editor window.](images/1_134/agent-host-harness-dropdown-editor.webp)

You can learn more in our [VS Code Agent Host documentation](https://code.visualstudio.com/docs/agents/concepts/agent-host). If you have any feedback or requests, please let us know by [filing an issue](https://github.com/microsoft/vscode/issues).

### Prompt timeline

**Setting**: `setting(sessions.chatTimeline.display)`

Long agent sessions are hard to navigate. A prompt you sent earlier can be a long way up the transcript, and there was no way to see at a glance where your prompts are or which ones changed files.

The Agents window now shows a timeline in the gutter beside the transcript, with a dot for each prompt you sent and a highlighted dot that marks your current position. Hover over it to open the list of your prompts, and select one to jump back to it. Prompts that changed files show how many lines were added and removed, and you can open those changes for review directly from the list.

Use the `setting(sessions.chatTimeline.display)` setting to show the timeline beside the scrollbar instead (`ruler`), or to hide it (`off`).

## Chat

### Find in chat

Finding something you remembered from earlier in a conversation meant scrolling back through the whole transcript. You can now search a conversation with `kb(workbench.action.chat.find)` in the Chat view, in chat editors, and in the Agents window.

The search covers the whole conversation, not only the part currently rendered on screen, so a match in a turn you scrolled past long ago is still found. Moving between matches scrolls each one into view, and expands the collapsed work summary when a match is inside one. You can match case, match whole words, or search with a regular expression.

## Editor Experience

### Open HTML files in the integrated browser by default

If you primarily preview rather than edit local HTML files, you can configure the integrated browser as the default editor with the `setting(workbench.editorAssociations)` setting or from the editor header. The browser includes the same features as a standalone browser tab, but remains associated with the HTML file. Links and other navigation therefore open in new tabs.
