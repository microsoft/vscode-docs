## October 23, 2026

### Compare models in local and empty repositories (Preview)

Run [model comparisons](https://code.visualstudio.com/docs/agents/run/compare-models) in local Git repositories without a remote or an initial commit, with each attempt isolated in its own worktree. For repositories without commits, attempts start from a snapshot of non-ignored working files without changing your source branch or index. _[microsoft/vscode#343622](https://github.com/microsoft/vscode/issues/343622)_

### Progressive worktree cleanup (Experimental)

Review and select measured worktrees while other sizes are still calculating, and follow **Cleaning up...** progress as completed rows disappear without reopening the editor. _[microsoft/vscode#343676](https://github.com/microsoft/vscode/pull/343676)_

### Manual cleanup of active sessions (Experimental)

Explicitly select worktrees for active sessions or sessions waiting for input in **Chat: Open Worktree Cleanup**, while **Select All** and automatic cleanup continue to exclude them. Running, pinned, and other protected sessions remain unavailable for cleanup. _[microsoft/vscode#343676](https://github.com/microsoft/vscode/pull/343676)_

### Preserve work before removing worktrees (Experimental)

Recover non-ignored working files from a dirty worktree removed by cleanup through the Git recovery reference and command recorded in the Agent Host logs. If preservation fails, cleanup leaves the worktree in place rather than discarding its files. _[microsoft/vscode#343676](https://github.com/microsoft/vscode/pull/343676)_

## October 22, 2026

### Session-aware voice conversations (Experimental)

**Setting**: `setting(agents.voice.sessionAwareness)`

Ask OpenAI BYOK [Voice Mode](https://code.visualstudio.com/docs/configure/accessibility/voice) questions such as 'Where were we?' or 'Which session needs input?' without starting a coding request. This enabled-by-default setting shares a bounded briefing of tracked sessions and recent active-chat context, including session titles, response summaries, pending prompt details, the selected model, and attachment names, but not attachment contents. Disable it and reconnect Voice Mode to restore input-only context. _[microsoft/vscode#343555](https://github.com/microsoft/vscode/pull/343555)_

### Faster GPT Live startup (Experimental)

Restart GPT Live Voice Mode sooner with fewer repeated model-discovery requests, while each connection still creates a fresh live session and checks credentials and policy. _[microsoft/vscode#343554](https://github.com/microsoft/vscode/issues/343554)_

### Preserve spoken clarification context (Experimental)

Keep your original request and clarification together when GPT Live hands an idle voice conversation to the coding agent, rather than submitting only your latest answer. Voice-only exchanges during ongoing coding work are not retained for later requests. _[microsoft/vscode#343549](https://github.com/microsoft/vscode/pull/343549)_

### Answer voice questions one at a time (Experimental)

Hear the full question when GPT Live narrates a single-question form, and answer multi-question forms one numbered question at a time. _[microsoft/vscode#343549](https://github.com/microsoft/vscode/pull/343549)_

### Steer ongoing work by voice (Experimental)

Send new spoken coding instructions as steering while the agent is working, applied at the next opportunity supported by the provider rather than queued until the task finishes. Steering does not guarantee immediate interruption. _[microsoft/vscode#343549](https://github.com/microsoft/vscode/pull/343549)_

### New-session composer enabled in Insiders (Experimental)

**Setting**: `setting(sessions.chat.experimental.newSessionComposerLayout)`

The experimental new-session composer is enabled by default in Insiders, keeping workspace, repository, and harness controls together above the chat input in the Agents window. Stable retains the previous default. _[microsoft/vscode#343498](https://github.com/microsoft/vscode/pull/343498)_

### Collapse session pickers to icons (Experimental)

Reduce clutter in the new-session composer by selecting **Collapse to Icon** from a picker's context menu, with per-picker choices preserved across reloads and Settings Sync. _[microsoft/vscode#343519](https://github.com/microsoft/vscode/issues/343519)_

### Filter worktree cleanup by workspace and age (Experimental)

Find session worktrees by workspace and inactivity period in **Chat: Open Worktree Cleanup**, with **Any time** selected by default to include recent worktrees. Changing the workspace filter clears the selection. _[microsoft/vscode#342635](https://github.com/microsoft/vscode/issues/342635), [microsoft/vscode#342633](https://github.com/microsoft/vscode/issues/342633)_

## October 21, 2026

### Keyboard access to session options (Experimental)

From the focused new-session chat input, use `kb(sessions.focusNewSessionEnvironmentPicker)`, `kb(sessions.focusNewSessionBranchPicker)`, `kb(sessions.focusNewSessionWorktreePicker)`, and `kb(sessions.focusSessionSyncAction)` to reach available composer controls without tabbing through the Agents window. The Sync shortcut only moves focus, so press Enter to synchronize. _[microsoft/vscode#343262](https://github.com/microsoft/vscode/issues/343262)_

### Worktree cleanup suggestions for low disk space (Experimental)

**Setting**: `setting(chat.agentSessions.sessionStorageCleanupSuggestion.enabled)`

When cleanup suggestions are enabled and a local worktree's disk has less than 5 GB available, the Agents window offers **Open Worktree Cleanup** below the Sessions list, regardless of worktree age or count. The action opens cleanup with **Any time** selected so you can review recent worktrees too. _[microsoft/vscode#343230](https://github.com/microsoft/vscode/issues/343230)_

### Localized spoken approvals in Voice Mode (Experimental)

**Setting**: `setting(agents.voice.language)`

Approve or reject GPT Live tool confirmations with explicit phrases in any of [Voice Mode's](https://code.visualstudio.com/docs/configure/accessibility/voice) 25 speech-recognition languages, with English phrases available as a fallback. Question forms also accept displayed localized choice labels, choice numbers, or free text where permitted, but ambiguous approval replies still require an explicit answer or the chat controls. _[microsoft/vscode#343299](https://github.com/microsoft/vscode/issues/343299)_

### Clearer Voice Mode connection indicators (Experimental)

Check whether Voice Mode is connected with a consistent blue indicator, including while muted, and identify an active OpenAI GPT Live connection in the Voice Mode hover. The GPT Live provider notice appears only on the first successful connection per profile instead of on every reconnect. _[microsoft/vscode#343323](https://github.com/microsoft/vscode/issues/343323)_

## October 20, 2026

### Separate environment selection in the composer (Experimental)

**Setting**: `setting(sessions.chat.experimental.environmentPicker)`

Choose where a new session runs independently of its workspace with an **Environment** picker for **This Computer**, **Cloud**, eligible remote hosts, and supported Dev Containers. This opt-in picker requires the experimental new-session composer in the desktop Agents window, and model comparisons are not supported in Dev Containers. _[microsoft/vscode#342686](https://github.com/microsoft/vscode/pull/342686)_

### Chat without a workspace from the composer (Experimental)

**Setting**: `setting(sessions.chat.experimental.workspaceOptOut)`

Start a chat without a project by selecting the workspace picker's **X** button on hover or keyboard focus, preserving your prompt and attachments. This opt-in action requires the experimental new-session composer and a harness and environment that support workspace-less chat. _[microsoft/vscode#342930](https://github.com/microsoft/vscode/issues/342930)_

### Named steps in model comparison setup (Preview)

See where [model comparison](https://code.visualstudio.com/docs/agents/run/compare-models) setup takes you next with **Configure Judge**, **Configure Attempts**, and **Configure Synthesis** buttons instead of generic navigation labels. _[microsoft/vscode#342744](https://github.com/microsoft/vscode/issues/342744)_

### Install Extension tool removed from the Local harness

The **Install Extension** (`#installExtension`) agent tool is no longer available in Local agent sessions. When you create a new workspace from chat, the agent no longer installs extensions. Instead, it adds the extensions the project needs to `.vscode/extensions.json`, so you can review and install them from the Extensions view. When you run a Python cell in a Jupyter notebook without the Jupyter extension, the kernel picker prompts you to install it.

If your custom agents or prompt files reference `#installExtension`, remove that reference. _[#343118](https://github.com/microsoft/vscode/issues/343118)_

### Run VS Code Command tool removed from the Local harness

The **Run VS Code Command** (`#runCommand`) agent tool is no longer available in Local agent sessions. Built-in workflows that relied on it now work without it. For example, when chat diagnoses network issues, it asks you to run **Developer: Chat Diagnostics** and share the report.

If your custom agents or prompt files reference `#runCommand`, remove that reference. _[#343125](https://github.com/microsoft/vscode/issues/343125)_

## October 19, 2026

### Compare models without a workspace (Preview)

**Setting**: `setting(sessions.chat.compareAgents.enabled)`

Compare model responses side by side in a folderless **Chat** in the Agents window, without a Git repository, judge, or synthesizer. Press `kb(sessions.compareModels)` to open comparison setup from an eligible chat input or model picker. _[microsoft/vscode#342578](https://github.com/microsoft/vscode/issues/342578)_

### Discover model comparisons from the picker (Experimental)

**Setting**: `setting(sessions.chat.compareAgents.showPickerHint)`

Enable the optional **Send Query to Multiple Models** action at the bottom of the model picker to discover comparison setup, with the hint retiring after you first open setup. Model comparisons must also be enabled, and the **Compare Models** toggle remains available after the hint disappears. _[microsoft/vscode#342905](https://github.com/microsoft/vscode/issues/342905)_
