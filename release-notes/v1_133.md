## Agents

### Agent host

The agent host lets you connect to the same agent session from multiple VS Code windows. It runs agent harnesses in a dedicated process based on the [Agent Host Protocol](https://microsoft.github.io/agent-host-protocol/) (AHP). The agent host's Copilot agent is powered by the [Copilot SDK](https://www.npmjs.com/package/@github/copilot-sdk), which aligns its behavior and functionality with the Copilot CLI, the standalone GitHub Copilot app, and other Copilot products.

We're actively developing the agent host. The screenshot below shows how to select the `Copilot` harness on the agent host in the editor window:

![Screenshot showing the harness dropdown in the editor window.](images/1_133/agent-host-harness-dropdown-editor.webp)

You can learn more in our [VS Code Agent Host documentation](https://code.visualstudio.com/docs/agents/concepts/agent-host). If you have any feedback or requests, please let us know by [filing an issue](https://github.com/microsoft/vscode/issues).

### Mix Anthropic and Copilot models in Claude sessions

A Claude session used to either run entirely through your GitHub Copilot subscription or entirely through however Claude was configured (like API key). You couldn't use both without reconfiguring the agent host every time. Now, we show both groups of models in the model picker, and you can switch between them mid-session with ease.

![Screenshot showing the model picker in a Claude session, with models grouped under an Anthropic heading and a Copilot heading.](images/1_133/agent-host-claude-model-picker.png)

The model you pick decides which one a session uses for the next turn. The model picker groups the two together: models under **Anthropic** bill your API key, and models under **Copilot** use your Copilot subscription. Pick a model from the other group mid-session and the session moves over on your next request.

### Open the Agents window without signing in to GitHub (Experimental)

The [Agents window](https://code.visualstudio.com/docs/agents/run/agents-window) used to open with a GitHub sign-in prompt you could not dismiss. That blocked anyone whose machine can't reach github.com or anyone who simply doesn't interact with GitHub. Users with Claude already configured with an API key who don't need GitHub sign-in had this extra step.

We're moving to a model where GitHub sign-in belongs to a particular agent or model, not to the window. To try it, enable the `setting(chat.agentHost.allowSignedOutWhenUsable)` setting. This will be gradually rolled out to all users in the next few releases.

![Screenshot showing the Agents window opened while signed out of GitHub, with a notification that reads "We've discovered your existing Claude configuration" and a Sign in to GitHub button.](images/1_133/agent-host-signed-out-claude.png)

Claude is the only agent that works this way today. This release put the foundation in place plus Claude support for it, so Copilot with your own model keys and Codex follow soon.
