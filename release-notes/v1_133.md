## August 6, 2026

* Add a **Copy Pull Request URL** action to the session context menu in the Agents Window. [#329364: Agents Window: Add Copy Pull Request URL to the session context menu](https://github.com/microsoft/vscode/issues/329364)

* Add support for middle-clicking a file to toggle it as viewed in the multi-diff editor. [#329350: Mouse middle-click could mark a file as "viewed"](https://github.com/microsoft/vscode/issues/329350)

* Add a **Show Editor Area** action to the Agents Window that restores the editor area. [#329375: Agents Window: Add a Show Editor Area action](https://github.com/microsoft/vscode/issues/329375)

* The integrated browser automatically reloads a local HTML file's preview when the file changes on disk. [#324391: Integrated browser: auto-reload HTML files on change](https://github.com/microsoft/vscode/issues/324391)

## August 5, 2026

* Add a header row to text file editors in the Agents Window, following the same treatment used by the Changes editor. [#328913: Agents Window: Add a header row to text file editors](https://github.com/microsoft/vscode/issues/328913)

* Persist the context window usage indicator's data per request. [#303357: Context window usage indicator data should be persisted](https://github.com/microsoft/vscode/issues/303357)

* Move the **Update** button to the right-most position in the title bar. [#323691: Move Update version button away from top task bar](https://github.com/microsoft/vscode/issues/323691)

## August 4, 2026

* Custom editor extensions can set separate priorities for standard text editors and diff editors. This lets custom editors remain the default editor while using the text editor by default for diff views. [#292379: Custom editors: Allow setting different priorities for edit/diff/merge](https://github.com/microsoft/vscode/issues/292379)

* Dictation stops automatically after you submit a chat message. [#328897: Dictation enabled after sending chat response](https://github.com/microsoft/vscode/issues/328897)

* The multilingual Nemotron 3.5 ASR on-device dictation model follows the language configured with `agents.voice.language`, including VS Code's configured display language when set to `auto`. [#328854: nemotron-3.5-asr-streaming-0.6b should follow VS Code configured language](https://github.com/microsoft/vscode/issues/328854)

* Add support for hiding the dictation and voice mode microphone buttons independently from disabling them. [#328797: Follow existing action bar patterns to hide buttons while maintaining functionality](https://github.com/microsoft/vscode/issues/328797)
