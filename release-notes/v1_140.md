## September 23, 2026

* Add support for Quick Chat on a remote agent host. _[#332468: Support quick chats on remote AH](https://github.com/microsoft/vscode/issues/332468)_

* Clearly label sessions that were started outside VS Code as external in the sessions list. _[#332361: make it clear that a session is external](https://github.com/microsoft/vscode/issues/332361)_

* Stop an active agent session when you mark it as **Done**, so that it does not continue to consume tokens in the background. _[#335786: Marking an active agent session as Done does not stop it](https://github.com/microsoft/vscode/issues/335786)_

* Use **Run Multiple Agents...** to send the same prompt to multiple agents in isolated worktrees and have a judge agent recommend the best result. _[#335085: Agents window: Compare multiple implementation attempts](https://github.com/microsoft/vscode/issues/335085)_

* Get contextual guidance for cross-posting a chat, such as when a new model is available or work can run in parallel. _[#337542: Use contextual text for the cross-posting affordance](https://github.com/microsoft/vscode/issues/337542)_

## September 22, 2026

* Open `file:` links that contain a drive letter from the Debug Console on Windows. _[#334283: Fix opening file: links with a drive letter in the Debug Console](https://github.com/microsoft/vscode/issues/334283)_

* Configure keybindings for the Agents Window workspace and agent harness pickers directly from their context menus. _[#337144: Agents Window pickers should support Configure Keybinding from context menu](https://github.com/microsoft/vscode/issues/337144)_

* View configured keybindings in the hovers for the Agents Window workspace and agent harness pickers. _[#337145: Agents Window picker hovers should show configured keybindings](https://github.com/microsoft/vscode/issues/337145)_

* Consistent layout and keyboard order for the new-session and running-session composer controls in the Agents Window. _[#337150: Agents Window should align experimental composer controls](https://github.com/microsoft/vscode/issues/337150)_

* Honor the Windows **Hide pointer while typing** system setting. _[#334254: Support for hiding mouse pointer on windows](https://github.com/microsoft/vscode/issues/334254)_

* Show a banner when administrators require a minimum VS Code version for AI features. _[#337086: Explain enterprise minVersion restrictions in Chat, the Agents window, and a window-level banner](https://github.com/microsoft/vscode/issues/337086)_

## September 21, 2026

* Add support for starting a chat on an eligible remote agent host without selecting a folder in the desktop Agents Window. _[#336544: Cannot create a workspace-less chat session for a remote agent host](https://github.com/microsoft/vscode/issues/336544)_
