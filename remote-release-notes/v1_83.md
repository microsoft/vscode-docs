# September 2023 (version 1.83)

## Dev Containers

### Connect to Dev Containers over Tunnels

Similar to SSH, you can now connect to Dev Containers over Tunnels. Only the Tunnel machine needs Docker installed. The Dev Container is built and run on the Tunnel's target machine, where the workspace folder must be located. Currently, the Tunnel machine must run Linux for Dev Containers to work. We plan to remove this limitation in a future milestone.
